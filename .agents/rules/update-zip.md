# Rule: Always Keep streamvance.zip Updated

Whenever any project files (e.g. `index.html`, `css/style.css`, files under `js/`, `functions/`, `public/`, `src/`, etc.) are modified, added, or deleted, you MUST run:

```bash
python update_zip.py
```

before finishing your turn or reporting back to the user. This ensures that `streamvance.zip` always reflects the latest project state without requiring the user to ask again.
